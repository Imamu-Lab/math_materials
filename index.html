      教材一覧

      中学校

      3教材

      外接して並ぶ円と多角形で作る面積の考察

      中学校の教科書に掲載されている問題をもとに、多角形の内部と円の内部が重なる部分（A）と、 多角形の外部と円の内部が重なる部分（B）の面積の性質について、図を操作しながら考察する教材です。

      中学校 ＞ 面積

      角の2倍の作図

      点や角度を自由に動かしながら、与えられた角の2倍の角を作図する手順を段階的に確認できる教材です。 円の交点を利用する作図の仕組みを、操作を通して視覚的に理解できます。

      中学校 ＞ 作図

      四角形PQRSと平行条件

      四角形の頂点を動かし、角の大きさの関係から2直線が平行になる条件を考察する教材です。 角度の自動表示と辺の色分けを通して、平行線の性質と判定を視覚的に確認できます。

      中学校 ＞ 平行線と角

      数学Ⅰ

      4教材

      2次関数のy軸方向への平行移動

      qの値を変え、y = 2x² と y = 2x² + q のグラフを比較する教材です。 定数項、頂点のy座標、上下方向への移動の向きと大きさの関係を視覚的に考察できます。

      数学Ⅰ ＞ 2次関数

      2次関数のx軸方向への平行移動

      pの値を変え、y = 2x² と y = 2(x − p)² のグラフを比較する教材です。 式の中の符号、頂点のx座標、左右方向への移動の向きと大きさの関係を視覚的に考察できます。

      数学Ⅰ ＞ 2次関数

      2次関数のx軸・y軸方向への平行移動

      pとqの値を変え、y = 2x² と y = 2(x − p)² + q のグラフを比較する教材です。 頂点の移動をL字型の矢印で捉え、式と頂点 (p, q) の関係を視覚的に考察できます。

      数学Ⅰ ＞ 2次関数

      単位円と正弦定理

      単位円上の3点でできる三角形を動かし、円周角と中心角、弦の長さの関係を段階的に調べる教材です。 中心角の二等分線を利用して、対辺の半分の長さにsinの値が表れることを視覚的に確認できます。

      数学Ⅰ ＞ 三角比
